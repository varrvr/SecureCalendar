# Secure Calendar: Private Set Intersection (PSI) with Bee2 & OPAQUE

**Тема проекта:** Разработка мобильного приложения для защищённого сравнения календарных событий с использованием протокола PSI и криптографической библиотеки Bee2.

## 📖 О проекте

Приложение позволяет двум пользователям (например, Алисе и Бобу) найти пересечения в своих расписаниях, **не раскрывая** друг другу полные календари и не доверяя свои данные серверу. 

Для сравнения используется протокол **PSI (Private Set Intersection)** на основе эллиптических кривых. Криптографические вычисления выполняются исключительно на устройствах пользователей. Сервер выступает лишь в роли «слепого посредника» для передачи сообщений и аутентификации.

### 🔐 Модель угроз (Threat Model)
1. **Сервер недоверенный**: Он может читать, задерживать или модифицировать сообщения, но не имеет закрытых ключей.
2. **Защита от ODA (Offline Dictionary Attack)**: Для входа используется современный протокол **OPAQUE (RFC 9807)**. Даже если база данных сервера будет украдена, злоумышленник не сможет подобрать пароли офлайн (используется библиотека `opaque-ke-py`).
3. **Защита от подмены**: Все сообщения PSI подписываются электронной подписью (bign) на клиенте (Bee2), а сервер не может их подделать.
4. **Приватность**: Сервер не знает, какие встречи есть у пользователей, и не видит результат пересечения.
