# Secure Calendar: Private Set Intersection (PSI) with Bee2 & OPAQUE

**Тема проекта:** Разработка мобильного приложения для защищённого сравнения календарных событий с использованием протокола PSI и криптографической библиотеки Bee2.

## 📖 О проекте

Приложение поддерживает локальные календари, OPAQUE-аутентификацию на Python-сервере и запросы между реальными аккаунтами. Пользователи и сервер могут обменяться приглашением и маршрутизировать непрозрачные сообщения.

Полноценный ECDH-PSI протокол пока отсутствует. Приложение честно сообщает об этом после принятия запроса: интервалы календаря не передаются серверу и приложение не показывает фиктивный результат.

### 🔐 Модель угроз (Threat Model)
1. **Сервер недоверенный**: Он может читать, задерживать или модифицировать сообщения, но не имеет закрытых ключей.
2. **OPAQUE**: Android и локальный Python binding используют одну конфигурацию OPAQUE RFC 9807: P-256 OPRF, TripleDH P-256/SHA-256 и Identity KSF. Межплатформенная регистрация и вход проверены instrumentation-тестом. Python binding локально собран из Rust исходников `server/opaque-snake-p256`.
3. **Криптографические ограничения**: Bee2 JNI предоставляет отдельные BIGN примитивы, но Android модуль ещё не реализует согласованный ECDH-PSI протокол, Hash-to-Curve для выбранной Bee2 группы или подпись транскрипта PSI.
4. **Приватность календаря**: HTTP/WebSocket слой не отправляет события или интервалы. До реализации PSI сравнение не выполняется.

Сервер и Android e2e настройка описаны в [server/README.md](server/README.md). Текущие криптографические ограничения — в `docs/security-limitations.md` и `docs/psi-protocol.md`.
